# Ilha — versões

Instaladores do Ilha, a Dynamic Island para o notch do Mac.

Baixe o `.dmg` mais recente em [Releases](https://github.com/pedromamare/ilha-releases/releases/latest), abra e arraste o Ilha para Aplicativos. Depois disso o app se atualiza sozinho.

`appcast.xml` é a lista de versões que o app consulta. Cada instalador é assinado; o app só aceita atualização com a assinatura certa.
